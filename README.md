Project Summary: Customer Sales Data Analysis

This project showcases my data analytics skills through the cleaning, analysis, and visualization of customer sales data using Python. I used Pandas for data manipulation and Matplotlib/Seaborn for generating business insights through visualizations.

Key Steps:
1. Data Cleaning: Removed unused columns, converted date formats, standardized column names, and verified revenue calculations.
2. Exploratory Analysis: Investigated revenue trends, top product categories, customer purchase behavior, and delivery performance.
3. Visual Insights: Created charts to highlight monthly revenue patterns, top-selling products, preferred payment methods, and delivery status distributions.

Key Findings:

1. Revenue peaks in November and January, indicating strong seasonal demand.
2. Clothing and Beauty are top-performing product categories by revenue.
3. Most customers pay via Credit Card or PayPal.
4. Delivery success rate is high, but some delays and returns suggest areas for improvement.

This project reflects how I approach data-driven problem solving—from raw data to meaningful business insights.
